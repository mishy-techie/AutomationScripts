# Beginner Projects

A collection of beginner-friendly **PowerShell scripts** designed to help build practical Windows administration and automation skills.

These projects start with simple PowerShell concepts and gradually introduce useful system administration tasks such as monitoring, file management, networking, backups, services, and security.

## 🚀 Getting Started

### Prerequisites

* Windows
* PowerShell 5.1+ or PowerShell 7+
* Basic familiarity with the command line

Clone the repository:

```powershell
git clone https://github.com/mishy-techie/AutomationScripts.git
cd AutomationScripts\BeginnerProjects
```

Run a script with:

```powershell
.\01-HelloWorld.ps1
```

If PowerShell blocks script execution, review your execution policy before changing it.

## 🎯 Learning Goals

These projects are intended to provide hands-on practice with:

* PowerShell fundamentals
* Windows system administration
* File and folder automation
* Networking and connectivity
* Processes and services
* System monitoring
* Backups and synchronization
* Windows event logs
* Software and hardware inventory
* Permissions and security
* Practical automation

## ⚠️ Disclaimer

Some scripts can modify files, services, system settings, or other Windows resources. **Review a script before running it and test potentially destructive scripts in a safe environment first.**
